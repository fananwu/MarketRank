明细

MarketRank · Fluxscape

本页面按 arXiv:2610.08946v1（B. Kaan Karamete《MarketRank: ranking stocks by the stationary probabilities of a Markov chain over estimated money flows, with a topological landscape view》——用估计的资金流构造马尔可夫链，按稳态概率给股票排名，并给出拓扑地形视图）的 §3–§6 与 Figure 5 固定界面实现。

怎么看这个页面

  • 中央地形：每只股票是一颗点（红=当期上涨、绿=下跌，点越大 πN 越高），山高 = log(π/s)（资金占比取对数）。标签直接标出代码/名称/涨跌，点标签打开个股详情；「标签」下拉切换 12/30/60 个，⚙ 里可调字号（小/中/大/特大），等高线上带斜体高程数值。
  • 缩放与平移：滚轮无级缩放，并朝鼠标所指的位置推进（放大看局部）；左键拖动旋转地形，中键拖动平移板面；双击空白处或 ⚙ 里的「重置视角」回到默认机位。
  • 全屏：中央地形右上角 ⛶ 进入全屏；按 Esc、点 ✕，或再点一次 ⛶ 均可退出。
  • 参数 ⚙：等高线间距（按 log(π/s) 等距分档，间距越小越密）、资金流粒子的速度与数量、网格线、持仓标记。
  • 悬停：停在落点或标签上约 0.4 秒后才弹出卡片（避免扫过时卡片乱跳），移开立即收起。
  • 点击：点标签直接打开个股大图；地形上的小球单击只选中（画十字线、联动其它面板），双击才打开个股大图（K 线 + 成交量 + πN 副图 / πN 轨迹 / 资金对手）。
  • ⤢ 放大：右侧「跟踪路径」「局部转移图」「当前标的」，以及「板块时间序列」都有放大按钮，进入全屏大图 + 数据明细表。
  • 时间轴：拖动、播放或点图表任意位置，地形、标签、排行、路径、转移图、板块序列全部按同一交易日联动。

模型（英文术语 → 中文）

  • π（pi） = 马尔可夫链的稳态概率（stationary probability），表示资金长期停在该股的份额；score = πN，1 = 市场平均。
  • φ = r·V·VWAP = 当日涨跌 × 成交额，即资金流强度；φ>0 为 sink（汇 / 接收方），φ<0 为 source（源 / 流出方）。地形上的飞行光点就是从 source 飞向 sink，抵达时有一圈接收扩散环，起飞时有一次闪亮。
  • correlation-tilted gravity（相关性倾斜引力）：aij = 1 + λρij，W 为 60 日收益相关；每个 source 只取最强的 top-64 个 sink。
  • 累积 T 后双侧剪枝（two-sided pruning：行 top-20 / 列 top-10），行归一化得转移矩阵 P。
  • damped power iteration（带阻尼的幂迭代）：π = (1−p)πP + p/N，p=0.15，迭代至 ‖Δπ‖₁<1e−10。
  • height = log(π/s)：s 为 20 日中位成交额份额，即资金占比的对数高度；heartbeat = Δlog(πN)，即资金脉搏的当日变化量。
  • territories（地块 / 社群）：20 根 bar 的资金流图上做 flux community（流量社群）划分，不是行业板块；再经 spectral order（谱排序）→ Hilbert curve（希尔伯特曲线）→ spiral（螺旋填充）→ IDW（反距离加权插值）→ CVT（质心泰森多边形松弛，12 格，λ=0.6）铺成地形。
  • truth（真值表）：精确排序表；地形只用来看趋势（论文 §6.8）。

数据

  • 日线：vipdoc/{sh,sz,bj}/lday/*.day（完整历史，只读），交易日逐日对齐。
  • 名称/价格标定：data/web_cache/20261106/*.cod；行业：tdxhy.cfg + tdxzs.cfg。
  • 板块成分：infoharbor_block.dat（概念/风格/指数）+ block.dat + 行业/大类/市场。
  • ETF/基金在链中参与计算，默认不落在地形表面（与论文一致）。

限制

论文结论：solver（求解器）可靠，但公开日线只含规模与少量时序信息，无法恢复真实的成交配对；π 不预测次日收益，flux communities 也不是行业板块。本页所有数值为按论文公式的本地重算，不构成投资建议。
